## 5. 第一组公开真人离线结果

使用最终构建的评价器与同一冻结子集，每个既有锁定模型只执行一次。40片段均通过原长度／能量门禁；全部10条校准数据来自5人，形成5个同人对和40个异人对。

| 指标 | CAM++ | ERes2Net-base |
|---|---:|---:|
| 模型维度 | 192 | 512 |
| 校准状态 | 分布重叠，failed_nonseparable | 可分离，separable |
| 校准同人最小相似度 | 0.3948524 | 0.4324242 |
| 校准异人最大相似度 | 0.4000929 | 0.3036193 |
| 冻结匹配阈值／间距 | 无有效阈值 | 0.3680217175／0.0161006155 |
| 25条独立评测评分 | 未执行，不写成0% | 25正确／0误归／0拒识 |
| 评测片段原生推理温态中位／P95 | 52.208／69.186ms | 140.2515／198.156ms |

CAM++仍提取了评测片段特征以记录独立推理耗时，但校准失败后没有评分或回退默认值；保留失败，不换语料或重跑挑最好结果。报告中的not_run及0占位不能当作0%准确率。ERes2Net的25／25只属于这25条近场、同设备、闭集语句，不是总体准确率或家庭现场PASS。

温态耗时基于25条评测推理中的后24次，首条评测推理分别46.033／122.176ms；模型已在登记／校准片段时加载，因此不是模型冷启动或整段真实聊天耗时。此处没有网络语音模型、CoreAudio、AEC、实体扬声器或实时换人路径的延迟测量。

公开语料新阈值只用于本轮离线报告，没有写入session、试点或产品。两个报告均为`human_acceptance=false`、`production_acceptance=false`、`feature_enabled=false`，开放集／分段／重叠均unavailable。结果支持保留现有ERes2Net作为下一阶段基线，尚不能决定采用某个模型或阈值进入产品。
