# 扫码后自动进入 Wi-Fi 页

用户要求扫码后去掉“发现附近设备”和再次点选机器人，只保留 Wi-Fi 选择、密码、连接。实现 `2d05587`、登录保护 `a011e39`，依据[设计](../superpowers/specs/2026-11-09-onboarding-auto-connect-design.md)与[计划](../superpowers/plans/2026-11-09-onboarding-auto-connect.md)。

## 实现
