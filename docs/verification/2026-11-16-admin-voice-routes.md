# 长期 A/B/C 语音链路与内部管理选择

2026-11-16。用户确认三条链路是长期产品能力；选择新链路时立即结束当前对话，再次唤醒或按键连接使用新选择。不是临时比较窗口，也不改变设备固件。

## 产品行为与边界

内部管理网页的设备“配置”页增加三个按钮：

| 选择 | 主回答生成方式 |
| --- | --- |
| A | Omni 接收原音、生成文字，再由 CosyVoice 合成 |
| B | Fun-ASR 转写、Qwen Plus 生成文字，再由同一 CosyVoice 合成 |
| C | 既有原生直接语音 |

未设置的设备保持 C。选择写入该设备的权威管理配置，每次接受显式保存均增加 revision，包括重复选择同一路；新连接重新读取。配置读取失败明确拒绝，不静默降级到其他链路。当前连接的链路固定，不能在一句回答中途更换生成器。

三路复用既有鉴权、业务前置、设备设置和音乐工具、近期记忆、表情、Opus、播放流控、设备回执和取消流程。A/B 当前完整合成后播放，C 保持原生流式播放；它们的起播时间与实际声音仍需现场比较。产品 A/B 使用有界的 25 秒输入、60 秒输出、正常正文限制，不继承历史比较工具的 120 字、四问或临时账本限制；原比较工具默认值保持。

管理持有选择、权限和版本，语音持有真实连接状态；通过已有 Unix 控制通道读取或结束目标设备连接，没有新生产服务或监听端口。公开接口仅为内部 `GET/PUT /api/admin/device-voice-route/:deviceId`；家庭端与公网不开放切换。PUT 需当前内部管理员、明确设备授权、设备管理权及匹配版本，事务内重新校验，IPC 后再次校验；撤权、重绑、过期和 A→B→A 迟到取消均有回归。

页面分别显示“已选择”和“当前实际链路”。点击前提示当前对话会结束，点击即保存，不加第二次确认。PUT 后 GET 回读；只有选择/设备/版本相符且结束回执确认才显示已切换。未知或未确认只显示保存事实，409/失败要求重新读取，不自动重发。隐藏、退出和切设备丢弃迟到结果。
