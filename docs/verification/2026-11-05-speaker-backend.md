# B／AS-Norm／质量感知校准：普通话小样本独立测试

用户批准继续测试[调研方案](../research/2026-11-05-speaker-b-optimization.md)，并在素材容量核查后选择保持普通话、增加小规模独立验证。[执行前设计](../superpowers/specs/2026-11-05-speaker-backend-design.md)及[计划](../superpowers/plans/2026-11-05-speaker-backend.md)分别记录算法和执行边界。此前50人结果见[登记与模型对照](2026-11-04-speakeropt.md)。

**本轮结论：保留B基线，暂不采用这套AS-Norm／QMF配置。** 新增独立测试中，按开发验证1%目标冻结的规则，B在Device03正确接纳13/14、陌生误接纳0/100；AS-Norm为14/14但误接纳13/100，QMF为14/14但误接纳9/100。Device06 PC中B为2/14、0/100，新方法为11/14但误接纳27/100及26/100。新方法未达到本轮误接纳目标；B的跨设备拒识也仍严重，不能据此称正式识别可用。

## 比较什么

- R0：Go＋sherpa-onnx＋锁定的ERes2Net-base，多段约20秒登记，cosine评分。
- R1：相同模型／音频／模板，增加AS-Norm，独立背景30人、每人2段融合、固定top-k10及总体标准差下限1e-6。
- R2：R1加本项目低维QMF变体：AS-Norm分数及log1p(VAD估计查询秒数)，训练标准化、截距共3参数；类平衡logistic、L2=.01、最多2000步、有界回溯。未收敛或分数权重非正则失败，不代换参数或隐去失败。

VAD不作为新查询硬门禁，也不裁剪或增强输入。三组共用一次energy合格特征提取，所有查询质量失败仍计入总分母。背景／训练／开发验证／最终已知与陌生人物完全分离。验证集标定1%／5%经验误接纳目标，同时要求验证已知误归0；测试不调阈值或margin。25条验证陌生录音只允许0／1条接纳，不能证明总体FAR保证。
