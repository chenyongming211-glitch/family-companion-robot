# 微雪取消闲置自动关机

用户说明前一轮等待按键采集时，微雪实际已经自动关机，并要求修改固件不再自动关机。空采集窗口不能解释为用户没有配合或麦克风拒识。

## 修改范围

专用微雪板原为`PowerSaveTimer(-1, 60, 300)`：闲置60秒进入屏幕省电，300秒调用注册的`pmic_->PowerOff()`。公共计时器以`-1`禁用对应时限。

新增补丁`0020-waveshare-disable-idle-shutdown.patch`仅将该板第三个参数改为`-1`，保留60秒屏幕省电、恢复和其它既有电源控制。公共计时器、其它板、Go服务、音频窗口、AEC／VAD和唤醒配置均不改。诊断准备工具兼容正式产品已禁用自动关机的情况。

源码提交：`23f1c5d89bd7559b226db2fffaf68b8b9346e80f`。方案见[范围说明](../superpowers/specs/2026-11-07-waveshare-no-auto-shutdown.md)。

微雪相关16项测试全部通过，包含此前采播锁和硬件代次保护；新策略下诊断树准备的兼容核验通过。运行测试和目标构建均在云端，Mac仅代码／Git和USB客户端。

## 已知边界

本项用于防止闲置期间硬件断电，不等于此前“小满”唤醒灵敏度、空输入误触发或真人打断问题已修复。相关验收继续以[插话回退记录](2026-11-07-waveshare-duplex-regression.md)为准。
