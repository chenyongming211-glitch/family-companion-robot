# 通话记忆与模型自然反问验证

日期：2026-10-24。基线`3e51117`。用户已确认让模型读取保存的通话内容，先理解并回答，确实有歧义才自行自然反问；程序继续维护实际播放进度。

## 实现

- drain每轮异步读取私有档案，提供当前/上一轮的转写和确认实播；未播生成稿排除，unknown明确标注。长记录使用有界近期原文、提取式摘要和出处，不冒充完整语义总结；模型可列会话、分页回查及搜索。更早于20份的会话可继续翻列表；跨会话搜索返回逐会话游标，禁止用全局seq遗漏其他会话。
- 去除关键词直达和固定状态问句。模型必须选择respond、ask_clarification或内容工具；完整tool_calls终态后执行单个工具，拒绝截断参数、工具外正文及并行状态修改。反问/查询回答走独立dialogue槽，完整实播进入助手历史；主/旁原稿继续保留。
- 旧于当前输入代次的真正未完成请求，与当前待理解输入分开。模型识别为控制/查询后清掉本轮临时标记，避免查询回复被打断后变成伪故事。读档本身不决定输出类型，读旧事实后创建的新故事仍可续讲。
- 文件快照限定读取时长度，避免追赶并发追加。JSON转义计入结果额度，长单条按字符偏移无损续读；private目录与安全打开沿用原存档约束。SDK报告历史也在工具写入处裁剪。
