# 按设备选择音频传输与插话能力

日期：2026-11-01（Asia/Shanghai）。本页按用户最新决定更新，取代之前“C3 继续推进 PCM 自然插话”的产品路线。

## 当前产品策略

| 终端 | 传输与交互 | 播放中语音插话 |
|---|---|---|
| Xmini ESP32-C3 | 保留已验收的 Opus 稳定按键版；按键开始连续问答、结束和重新开启 | 关闭。播放期间关闭麦克风上行，真实播放排空后恢复聆听 |
| 微雪 ESP32-S3 Touch AMOLED 2.16 | 保持现有 Opus 与对话流程 | 保持现有能力 |
| M5 StopWatch ESP32-S3 | 保持现有 Opus 与对话流程 | 保持现有能力 |

C3 的记忆、音量、身份、Wi-Fi、播放回报和按键交互继续保留。关闭的是播放期间的语音插话，不是取消按键结束或正常的多轮对话。设备能力按已验证的终端配置决定；新增终端需先验资源、网络和声学效果，不能仅凭芯片型号或算力推定已支持。

这次是稳定性优先的产品范围选择，不是证明所有 C3 硬件在理论上无法实现回声消除或插话。当前停止 C3 PCM/完整回声处理/自然插话的进一步开发和安装，不自动恢复旧试验。

## 共同服务端

终端继续复用同一套 Go Session、模型、鉴权与归属、近期记忆、设备工具和真实播放回报。C3 的播放期限制由终端的半双工上行门控实现，不修改共享 VAD、取消和 drain 规则，不降低微雪/M5 的能力。

格式仍须连接时显式协商，不在会话中自动切换或隐式回退。已有 Go PCM 支持和条件编译的实验源码可留作历史研究，不能据此把正常 C3 产品构建视为 PCM/插话已验收。后续若要重新启用，须由用户另行明确改变本策略并重新验证。
