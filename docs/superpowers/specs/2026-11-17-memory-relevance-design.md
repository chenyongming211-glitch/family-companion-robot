# 跨会话记忆按需参与回答

用户已确认：当前会话保留上下文，跨会话资料按关联使用，旧回答不能作为新回答的模板。此前仅加强故事提示未通过现场验证；带真实旧背景可复现37字开场，移除跨会话背景的单次隔离对照为150字完整故事。这支持历史影响的线索，不代表已确定提供方内部原因。

采用一个共用的无声语义选择步骤，复用现有 Native 工具调用与严格终态校验，不新增依赖/服务。当前会话实际已播上下文始终保留；跨会话候选仍来自当前鉴权设备的7天/24轮存储及现有有界投影。选择器只提交 none/recall/continue 和至多3个候选索引，不能执行设备操作、删除记录或产生用户可听回答。泛化的“讲个故事”、知识问答或自我介绍不因旧话题相同而选择旧回答；明确回忆、承接旧事或相关已知偏好才选必要资料。当前会话足以续聊时无需引入旧会话。

未选中的原话不进入主回答模型和业务规划背景。选择器失败/超时/无转写时保留当前上下文、略过跨会话资料，不假称历史不存在或已删除。选择失败不取消正常回答。新增一次至多3秒的无声模型请求，仅有跨会话候选时执行；记录真实耗时/用量，现场感受仍待验证。对话取消或清除记忆后，迟到选择不得重新带回旧资料。

对照方案：继续只加故事提示不能隔离无关旧答案；关键词筛选容易误解自然表达；直接取消所有记忆会破坏回忆和续聊。选择共用语义步骤，接受其延迟/成本，暂不合并音乐或设备控制规划器，以保持职责清楚。

改动由 `memory_selection.go` 负责只读候选选择与校验，`memory.go` 负责存储/清除/投影及选择结果重新核验，`session.go` 只调整共同回答入口次序，`identity.go` 说明选中的资料只是历史证据。A/B/C共用。保留聊天档案、现有记忆保存和清除、播放回执及身份权限。不开启产品mock，不改前端/固件/播放通道，不捎带修B合成故障。

验证：测试先证明“未选择的旧开场不进回答”“当前上下文保留”“回忆/旧故事只带选中内容”“非法/重复索引、工具或终态失败不放行”“取消和清除竞态不复活”；云端普通/race/vet/build，真实提供方有限新故事/回忆/续讲探针；实际来源最小补丁、独立审查及一次Voice发布。实机故事完整性与回忆/续聊由现场另验，不把合成结果称现场通过。
