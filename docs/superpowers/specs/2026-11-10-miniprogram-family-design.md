# 小程序家庭日常使用端

用户已批准按设备首页、聊天列表与详情、真实设置的顺序开发。本轮在现有原生小程序内交付这一条路径，复用家庭账号和 Go 管理服务，不引入新框架、服务或依赖。Mac 仅代码/Git与微信测试客户端，安装、测试、构建和部署在云端。

## 页面与导航

默认入口改为家庭首页；已有 `pages/index/index?scene=...` 设备码路径保持有效。登录后列出授权家庭及设备，可查看设备详情、聊天与设置。添加成功提供进入对应设备详情的按钮。唯一家庭自动选择，多家庭明确选择。新家庭首页使用已有蓝紫色、扁平图形与少量半透明背景；不采用复杂手势或动画。

家庭首页、设备详情、聊天列表、聊天详情、设备设置各自为简单原生页面。详情页必带设备 ID；聊天详情同时绑定聊天 ID 和设备 ID。首页提供添加设备、刷新与退出；空列表、记录更新中、无正文权限、网络失败、登录过期均明确反馈，不回退 mock，不把最后连接时间标为当前在线。

## 会话和隐私

原生页面各自独立打包，家庭会话 Api 放在原生 App 实例的共享 RAM 中；不写 storage、不保存密码。普通后台保留 RAM 登录，但清除正文视图和未完成请求；退出、401和账号切换使所有页及迟到回调失效。页面重新显示重新请求授权数据。添加设备继续使用原 Security2、认领与清理流程；它复用登录会话，但页面离开仅清除自己的配网资源，不退出整个家庭会话。扫码路径与普通首页导航不能互相丢失或错误恢复旧认领任务。

## 设备与聊天

复用 `/api/family/devices`、`/devices/<dev_32hex>`、`/chats?device=...&offset=...&limit=20`、`/chats/<chat_64hex>?device=...`。列表按服务端分页，不显示列表里未授权正文。详情分开呈现用户转写、已播文本、生成稿与保存/播放状态；未知停止位置明确显示边界不确定，不能把生成稿算作已播。保留服务端本次绑定后的正文权限边界，不导入旧历史。

## 本批真实设置

管理平台尚无硬件参数远程控制接口，本批设置范围收敛为家庭设备昵称、摆放位置，两项保存至云端并重新读取确认。昵称是家庭列表的展示名，与语音称呼及设备固件分离；配置中新增可选 `display_name` 覆盖展示，不覆盖既有 voice profile。音量、亮度仍展示未上报，不提供假保存或假下发。后续硬件控制需要独立的下发与设备回读实现，不计为本批完成项。

新增 `/api/family/device-settings/<dev_32hex>` 的 GET/PUT：GET 返回 `deviceId,name,location,version,canEdit`；PUT 接受 `name,location,version`，乐观并发冲突409。读取需当前设备授权；修改额外要求当前绑定家庭的 canAddDevices 管理权限，不能用内部管理员身份越过家庭授权。事务内重读权限与版本，私有审计成功后原子修改当前配置，只更改目标设备展示字段，保留账户、绑定、工厂身份、其他设备和历史。昵称复用现有12字校验，位置最多24字，拒绝控制符、缺失/null、额外或重复键。配置不可写/审计失败则明确失败。

## 部署和验收

公网 Caddy 仅新增具体家庭设备、聊天和设置路径，保持其他路径默认404。独立升级管理服务与小程序预览，不重启语音服务、不刷微雪或退货 M5。记录生产保护文件摘要和服务状态；真实配置备份只在云端私有目录。

测试覆盖 API路径/Cookie/401、跨设备权限、分页、未播内容、页面隐藏与迟到请求、配网共享会话、设置并发与非法写入。云端完成 Go race/vet/build、小程序测试/类型/原生产物验证，再检查微信开发者工具实际编译。用户现场打开手机及微雪新对话结果单列待验收，不以合成夹具代替。
