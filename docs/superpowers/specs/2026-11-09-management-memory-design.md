# 管理平台近期记忆只读接入

## 范围与已有决定

用户暂时无法做新实机发言验证，要求先开发其他功能。按既有平台P3范围与现有记忆策略，接入两端近期记忆查看；实机聊天验收继续待完成，不阻塞此只读功能。沿用当前账号、家庭/设备/正文许可和仅开放本次绑定后数据的限制；不新增留存或成员访问政策。

复用现有Vue记忆列表/详情与Go管理服务。展示语音服务实际保存的7天、最多24轮上下文片段，而非由聊天档案重新生成“记忆”。片段可能已截断，不等同于完整档案、长期人物画像或完整播放证明；展示用户文字、已保存回复、来源和可访问的源聊天链接。

## 最小结构

现有语音服务将快照保存在记录根目录`.memory/<SHA256(deviceID)>.json`，外层为recordstore.Snapshot，内层为memoryData.turns。管理服务利用已有只读记录目录挂载，以有界、锚定目录和普通文件校验读取，不能调用recordstore.Open/Load（它会加锁、清理或修改源目录）。不新增服务、依赖、数据库、写配置或挂载。

每次请求先验证当前有效绑定的正文权限，再按授权源manifest的sessionID/deviceID/绑定ID与版本加入快照片段。只有来源连接属于本次绑定且片段时间也在同一绑定内、未超过当前时间和7天范围才返回。其他设备、未知/旧来源、绑定前片段不返回。元数据权限不足时不打开快照。源聊天链接保留原连接ID；旧的连接详情行为不变。

快照文件最多1MiB、24条、累计24000 Unicode字符，原用户512/回复1024字符限制保持。校验外层版本/更新时间、内层字段/重复JSON键/重复轮次/时间/长度；损坏、超限、符号链接或非普通文件明确失败，不回退mock。目录存在但设备快照缺失，或有效内容全部过期/被授权过滤时为空列表；记忆目录缺失或不可读则为服务不可用。读取不延长记忆年龄、不创建锁、不清理源文件。

## 接口与页面

- `GET /api/{admin|family}/memories?device=<id>`：返回最多24项，按时间倒序；device必填且拒绝重复/未知参数。
- `GET /api/{admin|family}/memories/<memory-id>?device=<id>`：同样校验设备与正文许可，仅返回当前仍存在的片段。
- 记忆ID为`mem-<32hex sessionID>-<正整数 turnID>`；DTO沿用id/deviceId/conversationId/text/date，新增可选user/assistant/textSource/boundary。date为原片段RFC3339时间，页面本地化显示。
- 列表和详情在响应前追加无正文审计，action分别read_memories/read_memory；失败503，不输出正文。审计只包含账号/入口/操作/设备与记忆ID，不含查询原文或快照内容。
- 两端开放记忆导航、列表和详情、设备选择、手动刷新与源聊天链接。缺省选择首个真实授权设备，显式错误ID不回落。没有设备时有空状态；无正文权限、源损坏和请求失败明确反馈。
- 真实构建不显示/执行清除按钮；mock入口保留原交互。正文只在页面内存，不存浏览器storage。

## 验证与发布

全部Go/Node测试与构建在云端，Mac仅代码/Git和浏览器客户端。合成快照覆盖双家庭/角色/绑定前后、过期/未来、损坏/超限/路径逃逸、原子替换、审计失败和两端路由/详情/刷新；读取前后比较合成源字节与目录项，证明无写入。实际云端仅通过授权API核对空结果和只读挂载，原始快照正文不输出、不复制到Mac或Git。独立部署管理服务并核对语音PID/健康和保护摘要，语音进程、模型/固件/麦克风/播放保持原状。新实机记忆产生仍待用户后续发言验证。
