# 微雪爆音自动对照

用户要求逐项测试，随后明确不再反复朗读。改用单次诊断固件自动播放相同的400Hz、低幅度固定音频；不用真人输入，不把配置推测当根因。

当前基线：USB身份与历史微雪一致，启动ELF前缀5f2359074；用户确认安静、未碰触情况下仍有突然啪声。会话中的长回复734400/24000=30.6秒，最终全部完成播放回报；串口未记录故障锁存。短轮询AFE空缓冲不作为故障。屏幕关闭的真人对照没有完成，不能记成成绩。

先完整读取当前Flash，校验分区、应用与回退范围；只允许诊断应用写入既有应用槽，保留NVS、设备身份、资源和分区。生成物、备份、真实采样均不进Git。Mac只作USB测试客户端；编译、测试、原始采样分析在云端。

自动阶段依次为：直接PCM、预生成Opus、Opus优先级2→6、仅关闭屏幕、固定60ms节奏Opus、网络突发及网络固定节奏。每阶段相同音频、固定时长；单次只改变一项。原始优先级和亮度在阶段间恢复，NVS不持久写入。DMA先保持六槽，记录实际回填空缺和回调节奏，不盲改违反六槽契约的12槽配置。

两套诊断构建分别为六槽和十二槽；十二槽同时调整播放槽及TX/RX字节数校验。另加一个直接PCM幅度对照（3000→12000），保持设备音量不变。该幅度对照不冒充同一PCM；其余阶段使用同一400Hz/12秒输入。

诊断只增加有界、无分配的ISR计数；解码/播放积压用32位无锁原子快照。分别记录PCM空缺且解码积压、PCM积压、无积压的情形。设备原始双通道输入只在标记窗口存入预分配PSRAM，阶段结束后经USB转送云端私有目录，播放期间不传原始采样。Mac不打开麦克风。

数字缺料计数、网络间隔、物理输入采样共同判断；统计无异常不冒充听感无爆音。相同结果重复后才改正式实现；没有确定证据时保留未定因，并恢复原固件。诊断构建为独立手动workflow，不改变正式variant默认行为。
