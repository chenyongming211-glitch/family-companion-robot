# 管理网页UI/UX优化及去AI味

用户明确先用UI UX Pro Max重新优化，再用unslop去AI味；本批覆盖内部管理端与家庭网页，不扩展设备资料编辑/成员管理业务，也不修改小程序或固件。依赖/运行测试/构建在云端，Mac仅代码/Git/设计查询与浏览器，直接main，无分支/worktree。

## 当前审视与方向

真实页面截图显示：桌面家庭端600px窄列、设备面板被同列聊天高度拉伸留白、汉字首字作为底栏图标、通用欢迎标语、置顶完整页面目录及“真实数据/已接入”技术标记。品牌本身没有明显渐变/发光，不改产品名“伴伴”。

1. 产品：让家庭查看机器人状态、聊天与近期记忆，让内部人员管理获授权设备。
2. 性格：安静、清楚、稍有暖意。
3. 场景：家里的日常设备，灰白表面与已有陶橙色点缀，保留中文系统字体，不加载远程字体。
4. 重点：真实机器人设备行与已播/未播聊天事实；不添加虚构图表、营销图片或占位统计。
5. 识别细节：文字配合静态状态圆点，在线/离线/未知有明确语义，不用动画暗示不存在的实时行为。

UI UX Pro Max的自动组合曾返回营销落地页/深色推荐，与本产品不符；采用其Flat Design、44px触摸目标、4.5:1文字对比、焦点/响应式指南，保持现有Vue3/CSS。unslop来源为Damir Sokolovsky的heydamir/unslop，CC BY4.0；技能已安装到用户目录，下轮也可直接使用。

## 两轮执行

- UI/UX轮：统一4/8px间距、14/16px正文与28px标题、字体400/500/600；修正表单/列表/按钮层级，导航用同套18px Lucide线图标；桌面家庭端内容最多1200px并双列、手机底栏和44px目标；灰白表面与#9c4b24主操作色。
- unslop轮：在第一轮实际页面基础上按spacing/color/icons/copy/type/layout/details/visuals/motion九项复核，删除通用欢迎话术和技术徽章，把页面目录降为辅助入口；精简解释但保留授权、未知值、播放事实、清除确认和回执失败说明。只修复审视到的问题，不生成图片、视频、动效或装饰卡片。

## 保持的边界

所有API/权限/隐私失效、真实账号登录、隐藏清正文、轮次/播放信息、音量亮度松手整10提交、50秒等待和回执匹配保持。状态不靠颜色独立表达；unknown不显示绿色在线。原页面/链接仍可进入。桌面与手机无横向溢出，正文可读；系统深色偏好也保留本批明确的浅色主题，不新增主题切换。

无后端/Voice/固件/数据迁移/实际调节或清除，不改Caddy/防火墙/旧中断事务基线。只原子替换静态资源，原管理与Voice进程/参数、配置/记录/记忆、权限/审计前缀等保护保持；只清理此次无引用旧真实静态资产，不保留mock产品。原CI DNS故障仍单独未关闭。

## 验证

云端既有52项行为测试、类型/构建；标题文案变化只更新现有App认证行为用例的预期标题，不降低隐私断言。最终用375/768/1024/1440视口检查溢出、44px目标、焦点与对比度；实际两端登录/设备/控制只读、聊天/记忆/来源/审计，截图不含聊天正文。用户原audio-capture三文件及M01文档保持。UI原图、两轮摘要与构建来源保存在忽略scratch与云端，不把截图/产物/凭据写Git。
