# 小程序扁平与半透明主题

用户已明确要求参考所附两张微信小程序截图：蓝紫配色、扁平图片/图标，局部半透明叠层。本次以浅底彩卡为主，蓝紫头部及柔和波浪为点缀；应用到现有添加设备流程。

范围：重做顶部插画、步骤图标、登录/扫码/设备/Wi-Fi/等待/完成卡片及按钮。四个图标表示账号、设备、配网、完成的进度，不新增没有业务支持的首页/帮助/最近/我的导航。保持现有家庭登录、扫码、加密、权限、取消清理及仅云端confirmed显示成功的条件和全部事件绑定。

视觉：主色约#4D58EF，浅底#F4F6FF，白色卡片，少量薄荷/淡紫辅助色。文字使用系统中文字体，正文约32rpx、辅助文字28rpx；输入/按钮触区至少88rpx，内容留白24–32rpx，圆角约24–32rpx。半透明仅用于蓝紫头部波浪、插画面板及局部图标底；不依赖backdrop-filter。图标用原生view与WXSS几何线条/色块，避免emoji、图标字体、外部图片或新增依赖。

验证：云端既有70项行为测试、类型检查、打包及真实WXML阶段校验；微信开发者工具实际检查首屏、错误、设备/配网/等待/成功的条件布局和预览打包。375/390宽度及长文本不横溢。视觉变更不代替真实手机BLE/设备验收。
