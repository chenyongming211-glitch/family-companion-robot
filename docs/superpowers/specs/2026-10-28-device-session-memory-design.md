# 小满同设备跨会话记忆第一期

状态：用户已批准上一轮方案并要求直接开发；本文件细化实施边界，不新增审批步骤。

## 用户体验

同一鉴权设备结束对话、重新唤醒或服务重启后，可依据近期记录回忆和语义续聊。设备不是个人身份，M5与微雪不共享记录。不做声纹、个人画像、全部历史检索、提醒或精确逐字续播。

默认有效期7天，最多24轮；每轮用户最多512字、助手最多1024字，总量最多24000字。模型每轮收到此前会话近期原话（总量最多6000字）及更早记录的有来源短摘录（最多6条，每条用户100字/助手180字）。摘录是原话截取，不伪装模型提炼出的事实；不新增摘要模型调用。当前会话仍使用既有16轮已播上下文。

## 存储与可信边界

复用internal/recordstore的有界私有快照、单写入队列、原子替换、回执与过期清理；新目录位于当前records/.memory，不读旧网关记录、不从日志回填。存储键来自服务端鉴权Ownership.DeviceID，缺少归属的旧客户端不启用。每条记录带session_id、turn_id、时间、用户转写和播放证据；只使用PlaybackEvidence.SpokenText，保留完整/部分及识别可能有误的信息，未播生成稿不保存。

每Session后台合并快照，转写、播放回报、ASR和生成结束触发合并；音频路径仅投递非阻塞通知。关闭时收尾保存，释放同设备租约后才允许重新接入。读取/写入失败记录状态，对话可继续，但模型不得宣称已可靠记住。条目独立按原时间过期，重连不延长旧条目寿命。模型上下文中历史是资料，不能触发设备操作或改写身份。

输入转写就绪后，生成前核实本轮输入的保存回执，成功才能确认已记录；记忆与设备控制共享一个最多300ms的转写预算，避免叠加等待。磁盘写入最多等2秒，故障降级保留正常问答。超过原工具规划器输入上限时，仅移除可选的跨会话背景，不让新增记忆禁用原设备控制。

## 清除

首期提供明确语音命令“清除聊天记忆”，兼容有限的完整同义命令及礼貌前缀。仅匹配当前整句，引用、否定、问题、其他设备目标、混合表达不删除；“从头开始”不作为删除命令。普通回答仍由模型自然生成。

清除持久快照后阻止当前会话清除点以前的内容再进入模型和快照；播放历史结构保留以处理迟到回报。清除与后台保存串行，杜绝旧保存复活；清除请求本身不保存。回执确认前不声称成功；读取状态核对空快照。原始通话日志保留，不宣称删掉全部档案，且不从这些日志重新恢复记忆。断开、取消不撤回已经提交的删除，不重复执行。

## 验证与上线

运行测试、依赖与真实模型探针仅在云端；Mac编辑/Git，不启本地语音服务。本轮不刷固件、不自动发声。先RED后GREEN覆盖重连/重启、双设备隔离、部分播放、完全未播、失效/损坏、清除并发与迟到回报、普通对话/搜索/控制/插话兼容。全仓race、vet、build后以真实模型和模拟播放验证，空闲发布并留二进制回退；真人听感单列。
