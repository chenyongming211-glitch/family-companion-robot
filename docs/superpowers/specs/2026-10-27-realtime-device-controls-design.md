# 当前 Go Realtime 接入设备语音控制

用户已批准继续：双设备实机收尾在本轮按用户决定结束，下一项为当前对话设备的音量、亮度、状态查询。M5/微雪同房间互相接话已由22:37—22:42记录确认，是已知声学问题，单独保留，不作为本功能前置阻塞；未实际执行的声学/功耗测试不能补记通过。

## 行为与范围

复用 `internal/devicetools` 的固定白名单、参数校验、发现/调用超时及设置后回读。支持绝对音量/亮度0—100、相对调节先读后设、亮度0表示息屏、状态查询只返回音量与亮度。只控制鉴权绑定的当前WebSocket设备，不接入其他终端、家电、重启、配网、任意MCP工具、判题、提醒或长期记忆。Mac不声明设备能力。无需改变现有两板固件。

原生千问 `tools` 与 `enable_search` 互斥。本轮采用独立、无声的工具会话：工具会话search=false、modalities=[text]，负责理解本轮明确控制请求并发出Function Calling；正常语音会话沿用原模型/音色/搜索参数，不注册工具。工具执行/回读后的受控结果作为结构化事实供正常语音会话使用；包含天气等混合请求仍由正常链路继续联网回复，不用全局关闭搜索。

2026-10-27已在云端对真实当前模型进行无设备副作用探针：text-only会话及工具注册被接受，文本“把当前设备音量设为20”返回device_set_volume(volume=20)，response.completed，无音频或硬件执行。证据仅存云端私有目录。

## 处理流程

1. 小智hello声明MCP后，每会话独占一个Bridge执行initialize/tools/list，只使用预置的3种工具定义。发现和调用不阻塞音频读取；未声明MCP的旧客户端、Mac与原语音流程兼容。
2. 复用现有监听通道的ASR文字，为当前轮次等待一个短而有界的转写窗口。普通聊天不另开工具模型；设备调节相关词只作候选筛选，不能直接驱动硬件。候选先做服务端目标授权：明确指向另一台/其他房间/手机电脑家电，或禁止操作当前整台设备时，不调用规划器、不发MCP，并向原语音链路提供未执行/目标不支持的结构化事实。清楚的“不要调手机，调你自己的”仍可处理当前设备；“音量别动、调亮度”不是禁止整个设备。混合目标无法清楚区分时不替换为当前设备，交语音澄清。模型继续理解引用、否定、提问和相对操作，但目标授权不能只靠提示词。转写缺失不猜测控制参数，原音频仍可走语音回复。
3. 工具模型仅收到当前请求与近期已播上下文。明确相对调整必须先查询当前值；不能引用历史状态冒充当前读取。最多8次调用，调用字段和输出有界、call_id去重，避免循环/重复执行。每轮工具处理有独立总时限，失败后普通语音仍可自然说明未核实，不声称已调好。
4. 所有MCP请求通过本Session的socket发送，回应按当前session与JSON-RPC ID匹配。兼容固件省略session_id的MCP初始化回应，但拒绝非空错误scope。设备提供的任意描述/网络字段不进入模型。
5. 只有Bridge返回ok=true且verified=true才允许确认设置成功。超时、读取不一致、断连或取消均不能生成伪成功回执；不自动重试设置。亮度渐变沿用原模块的有界回读。
6. 开口打断继续沿用取消生成与旧音频排空。取消当前轮次时同步撤销尚未下发的工具操作，迟到结果不能触发旧轮次续答；已经下发的物理设置不能回滚或声称已撤销。工具不能绕过当前轮次取消检查。
7. 每会话能力按实际发现结果报告。语音身份提示与当前能力一致；没有本轮工具回执时禁止声称已执行控制。记录仅保留固定工具名、参数、受控结果、轮次及既有device_id/session_id，不保留凭据或设备原始状态全文。

## 验证与发布

- 云端TDD覆盖真实Bridge发现/读写/核验/失败、每设备隔离、错误scope、迟到回应、取消、重复call_id、相对调整及未声明客户端兼容。
- 假上游WebSocket覆盖text-only Function Calling、多次读→设、结果回填、无工具回合、重复/错response ID/超限、取消与原search=true流式回归。
- 候选路由覆盖中文自然表达、英文控制、后续相对调整及普通聊天；语义否定/引用/其他设备由真实模型探针验证，不宣称词表等于意图理解。
- 目标授权回归必须使用不合作的模拟规划器：即使规划器要调用当前设备设置，也不能穿过明确其他设备目标/当前设备禁令。真实模型探针保留失败记录后复验，不能以补充一句提示词代替执行边界。
- 全仓Go race/vet/build在服务器执行。真实模型+模拟设备验证音量、相对调节、亮度0、失败不冒充成功、混合搜索及两个设备隔离；模拟MCP不算实体执行通过。
- 通过后空闲部署18040/18041，保留二进制、unit及既有身份/记录回退，不改凭据/注册表或刷固件。真人对各设备说控制命令并核对实际效果，另列待验收，不捏造实机结果。
