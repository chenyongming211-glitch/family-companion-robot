# 微雪取消闲置自动关机

用户报告采集等待期间设备已经自动关机，并明确要求修改固件不再自动关机。本次只处理这一前置条件，不将其视为唤醒、AEC或语音打断问题已解决。

现有专用微雪板以`PowerSaveTimer(-1, 60, 300)`在闲置60秒后进入屏幕省电、300秒后请求PMIC关机。公共计时器已支持`-1`禁用关机。

采用最小修改：该板改为`PowerSaveTimer(-1, 60, -1)`，保留屏幕省电／恢复、现有手动电源控制和其它电源逻辑。相比完全关闭省电计时器，该方案保留屏幕行为；本次不新增按供电方式切换的另一套策略。

改动通过固定上游补丁进入正式产品构建。仅更新目标微雪的app槽，保留分区、NVS、设备身份和原资源；生成固件与备份不进入Git。Go服务和现有音频参数保持。

验证：云端使用实际板级构造参数与公共计时器代码，复现旧策略在闲置期间触发关机，再验证15分钟模拟闲置不请求关机、60秒屏幕省电及恢复仍生效。通过既有目标构建和产物核验后刷入，实机保持闲置超过原300秒关机点，观察持续运行与USB在线。不要求用户反复朗读。
