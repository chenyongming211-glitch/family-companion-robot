# 微雪唤醒诊断入口

用户要求继续修复“小满”唤醒，闲置关机的实机确认留后。正式产品23f1c5d已刷入，未修改唤醒／AEC／VAD。已有按键会话与限时窗口多次错开，不能再把语音刺激播放或按键连接误记为语音唤醒成功。

增加仅手动诊断workflow使用的源码注入工具，不进入正式产品默认构建。通过本机USB有限命令，调度现有对话键的正常应用入口，仅在idle启动、listening结束；不绕过AEC就绪、协议鉴权或模式协商。命令白名单为status／start／stop／probe 1～10秒，无shell或外部网络控制。

诊断窗口按100ms输出原始Mic／参考声道与AFE处理后单声道的计数、DC／RMS／峰值／削波，只记录数值，默认关闭、最长10秒。任务中计算局部统计，短portMUX仅合并快照，不在ISR计算或打印；代次隔离防止旧统计混入新窗口。无原始声音经USB落到Mac。

目标是自动比较固定声源的低／正常音量、静音背景、待机唤醒与按键会话采音，区分输入过小、AEC抑制和模型检测问题。采音入口只算USB启动，不算声学唤醒。正式阈值和增益在证据出现前不改；诊断结束恢复23f1c5d产品固件，保留身份／配置／原资源。

## 识别阈值隔离对照

首轮诊断固件bae4a3a在用户确认安静后，固定合成音四次唤醒，用户正常音量一声也唤醒。进入60秒屏幕省电后固定音仍唤醒。之后一次USB启动业务会话中，云端实际收到6.88秒、25字非空转写的测试问句；首轮回复随即被0.72秒空转写输入替换。结束会话后，同一四分之一播放音量的唤醒音连续两次漏检，Mic／AFE峰值约980／975和989／989、参考峰值2、无削波、wake=1；提高声源音量一倍后检测0.681770。未证明ADC增益不足，也不把声源加大等同于数字增益。

下一轮只在手动lab中增加`wwd threshold 15`与`wwd threshold 20`，仅idle允许申请，由MultiNet喂入任务持输入锁时应用并单独回报；默认20，只有两个可选值。业务采音／AEC／ADC增益／Go服务／原资源均不变，正式默认构建不包含这条入口。假设是这类漏检与识别阈值余量有关；对照不能预先当作修复。

先固定本轮素材与顺序，再以20→15→20三段运行：每段5次同一低音量正例、5次相近词负例；每个正例之间通过USB正常结束，失败也保留分母。每段另测背景静音。正例统一播放增益0.25，负例0.5；相近词为“小马”“小王”“慢慢”“你好”“小明”。每次必须处于idle且实际应用阈值已确认，不能把按键／USB启动算语音唤醒。候选若出现误唤醒、没有改善或回退20不能重现趋势，不升级为正式修复；保留所有试次。合成音对照不替代真人、多人／距离／噪声验收。
