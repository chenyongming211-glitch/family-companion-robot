# 电脑麦克风登记素材采集

2026-11-07。用户当前没有手机，询问能否改用电脑采集。本轮采用当前Mac直接收人声，条件明确改记为“电脑麦克风登记→机器人查询”；手机条件继续待验。现场目前一位参与者，其他成员及陌生人后续安排。五人／逐人19of20／零误归／陌生0of200不变，不以一位参与者代替完整验收。

## 最小客户端

新增隔离AppKit测试客户端，打开窗口不连接、不申请麦克风、不收音。每次手动点击后先通过已有SSH身份启动有界云端接收器，得到ready才请求麦克风权限并录4秒。每段完成后停止麦克风，收到云端保存确认后才允许下一次手动采集。关闭／取消立即停止收音及本客户端SSH子进程；代次保护排除迟到回调。没有扬声器播放或自动重试开麦，不启动本地语音服务。

Mac只取得AVAudioEngine原生Float32采样，保留实际采样率和全部输入声道，明确交错小端f32le封装；不启用新的Voice Processing或降噪，不在Mac做声纹、VAD或重采样。限定8000～96000Hz、1～8声道、4秒、最多16MiB；格式或样本不足即失败。原始声音只在有界应用内存和SSH管道，不写Mac磁盘。麦克风源选择保持系统当前输入，元数据标明AVFoundation来源，不能称为原始ADC。

窗口显示同一位参与者／单人环境／自愿录音说明、逐条不同提示句、已保存数量和状态。提示每句说满约4秒；建议至少6段候选登记素材，但是否足量由云端质量判断决定，不能将6×4秒原录音当20秒净人声。源和角色使用私有匿名M01等，不登记姓名或提取声纹。

## 云端协议与保存

每次SSH执行独立receiver，显式指定既有私有根目录和新随机clip ID，不开放网络服务。ready之后接收4字节大端JSON长度、严格固定header和原生f32le数据。header包含版本、采样率、声道、样本帧数、字节数及固定source_kind／device／format。约束和重复字段严格校验，数据后须EOF；60秒内收齐，不完整／超限／非有限浮点均固定失败。错误不输出音频、任意异常或正文。

复用采集器安全文件创建，目录0700、文件0600、排他且不跟随链接。保留`source.f32le`原件与摘要。使用云端既有ffmpeg固定选择第0输入声道、转换16kHz mono s16le，再由Python写规范WAV，记录ffmpeg版本、原生／规范格式、时长、字节数、能量／峰值／削波和两个摘要。原始采样率和全部声道保留，可独立审查声道选择；不隐式选择得分更好的声道。

响应仅固定stored/incomplete、clip ID、时长、样本数和归一化RMS；不返回音频或声纹。元数据`private_human`、`computer_enrollment_candidate`、所有identity／human／production验收false。接收器不加载模型、不匹配身份、不改正式服务、阈值或设备配置。

## 验证与现场

云端先RED→GREEN验证严格帧／字段／长度／EOF／超时、非有限浮点、路径与权限、原件摘要、声道0与固定格式转换、失败清理；Mac只做客户端SDK构建、无麦克风状态／生命周期测试和签名检查。独立规格及质量复核后才打开新App，代理不点击开麦或系统权限。

先由用户手动采一段，核对实际输入格式、云端原件与WAV、来源及质量，再继续不同短句候选登记素材。机器人登记素材需另批采集；就绪录音不自动改标登记或最终查询。有效量、分会话／内容隔离、独立开发及最终查询仍按原协议执行。
