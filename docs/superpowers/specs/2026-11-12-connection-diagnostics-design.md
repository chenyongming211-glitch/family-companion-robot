# 微雪语音连接诊断

用户已批准按“固件阶段日志 → 后台关联 → 隔离故障复现 → 有证据的修复”执行。本批只支持微雪 ESP32-S3 2.16，直接在 main 开发。不是已确认根因的重连修复。

## 已知事实

2026-11-12 现场报告按键后一直显示连接。故障窗口内约5秒心跳、设备绑定和引导/语音入口鉴权正常，主循环堆遥测继续，未抓到最初按键到失败的完整过程。用户自行重启后5轮对话、5份完整 I2S 播放回执，后端进程未重启。旧会话曾发生 drain_timeout，尚不能证明与此次卡住有因果。AFE空缓冲告警在恢复后也出现，不作根因。

## 实现边界

- 共用固件连接诊断模块负责启动随机编号、连接计数、设备单调时钟、阶段/数值错误/状态和当前可用内存；不负责授权、重试、重启或修改音频策略。
- `X-Robot-Connection-Id` 格式固定为 `c1-` 加16位小写十六进制启动随机值、`-`、8位小写十六进制连接计数（总长28）。它仅关联日志，不是身份或授权依据。旧客户端无此头仍按原规则处理。
- 通过现有 NetworkInterface/Tcp 接口的薄适配器观测 TLS 开始/完成/失败、升级请求发送、首个HTTP响应状态。TLS阶段包括该驱动内部的DNS/TCP/TLS建立；不能声称进一步区分了DNS与TLS握手。适配器直接转发全部业务字节和原有返回值，不修改或复制供应商实现。
- 应用记录按键/唤醒处理、进入连接、继续连接、收到hello、进入聆听、断开与恢复；已在连接中再次按键也留下状态记录。每个socket固定使用创建时的诊断编号，迟到回调不能误标到后续尝试。
- Go设备入口只记录合法编号及固定阶段、数值HTTP状态、耗时、服务端会话标识；覆盖到达、鉴权、容量、升级、hello和会话进入/退出。无合法编号不增加日志。不得输出请求头、凭据、URL查询、Wi-Fi资料、音频或正文。
- 不增加服务、依赖或管理页面，不修改家庭、工厂身份、Wi-Fi、偏好和历史；不修改防火墙或原未收口审计事务。

## 验证及安装

先在云端执行诊断与实际方法的失败/重连测试，覆盖旧关闭回调、TLS失败、升级拒绝、握手无响应、断开后再次连接及诊断脱敏/编号隔离。隔离测试不连接真实模型，不冒充实机Wi-Fi/24小时待机。

微雪原生构建须核对来源、SDK配置、分区和资源，复用已核对工具链及缓存，只构建当前支持目标。安装前确认无真实语音会话和有效认领任务；新备份仅存云端，核对目标MAC。只更新活动应用槽、整槽回读并验证槽外不变，保留当前NVS/绑定，不刷完整旧镜像。后台仅更新语音服务可执行文件，保护现有配置、数据及管理服务。两端上线后核对同一编号；未捕获本次原始卡死前，根因状态保持待定位。
