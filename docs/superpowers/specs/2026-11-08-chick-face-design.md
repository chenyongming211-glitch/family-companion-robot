# CHICK-01 参数化表情接入

状态：用户已于2026-11-08明确采用新表情清单、先设置小鸡翅膀款，并取消小光球；本文件将该决定转为实现约束。

## 采用的设计

已通读资料目录的五份文档及小鸡概念图。屏幕采用《CHICK-01_屏幕表情系统清单_v1.0.html》的深色背景、暖色眼睛、腮红与参数化脸。先用通用表情，不新增小鸡喙、翅膀电机或角色化动作。微雪2.16英寸现有屏幕先运行，240×320设计画布等比适配480×480及M5圆屏；没有给现有开发板更换屏驱动或采用参考文档中的三段式音频。

使用12组系统参数、15组情绪数据及5类微动画。19个已有情绪字符串全部映射；网页中的thinking没有独立L1预览数据，复用系统思考参数，crying保留泪层。未知字符串回平静。系统状态并非12项DeviceState逐项对应：低电和充电取电源事实，思考取云端真实生成状态，不靠等待时长推断。

## 显示与优先级

- 用户补充：L0系统状态必须配文字描述，L1情绪和L2微动画不显示名称或解释。底部状态文字独立于情绪，开心/困倦等脸型不能将“正在聆听/正在说话”改成情绪名称；具体系统通知仍显示其实际内容。
- L0文案：小满启动中、等待配网、正在连接、待机中、正在聆听、正在思考、小满正在说话、小满有个提示、设备异常，请重试、正在升级、电量低，请充电、正在充电。采音尚未就绪显示“正在准备语音”；打断排空时显示“正在停播”，不提前宣称已停止。屏幕关闭/系统预览占用时不显示脸及其文字。
- 开机、配网、连接、待机、聆听、思考、说话、提示、错误、升级、低电、充电均有参数预设；升级/错误优先，配网/预览/低电弹窗保留系统页面所有权。
- 待机显示新的脸；现有60秒低亮只降低动画频率，不自动换成sleepy或旧小智图标。sleepy仍是明确情绪事件可使用的表情。闲置自动关机继续禁用；不改已有电源按钮和电池保护。
- 聆听必须依据当前capture/epoch的采音门；实际DMA播放中的嘴型优先于排空期间收到的聆听提示。无效、过期或旧连接音频观察不驱动嘴型。
- 说话保持情绪，嘴型从真实DMA完成的幅度观察平滑到60ms；不在待播PCM处新增计算或调用显示。沿用已有音频观察实现，旧orb命名仅可作为内部兼容观察接口，不再有小光球视图或配置。
- 眨眼、4秒呼吸、待机视线跳动及小动作只在UI任务运行。正常表情15fps，口型目标30fps、静态和低亮可降频；超预算时只降低UI速率。缓存仅PSRAM；分配失败显示静态简化脸，不能挤占音频内部RAM。
- 流式同预设800ms内不重新启动；情绪最多5秒，结束说话后保留最多2秒。状态变化立即生效，150ms插值不延迟实际状态。

## 实现边界

小光球的显示代码、入口和产品配置取消；保留其经过验证的音频观察能力。新界面用固定240×320 RGB565参数化画布，153600字节PSRAM，不引入逐帧资源或修改分区。参考文件的CPU、Flash和声学估计不当作实测结果。

当前实机为23f正式基线。main的0021唤醒窗口实验未通过验收，新增明确的默认关闭开关；隔离wake lab可显式启用，表情产品构建保持关闭，不能随本次界面更新重新带入。

为真实显示思考，固件hello协商face_state_v1；Go仅向协商设备把已有thinking/listening状态转换为既有llm消息的可选state字段，与emotion字段分开，不制造TTS开始，不增加模型调用。开始真实DMA播放、生成完成/取消/失败或退出会话会清除等待提示；明确的model_thinking状态可持续到真实终止，L1 thinking情绪仍有5秒上限。普通情绪接收、映射和渲染全部具备，但当前模型链路没有产生的开心/难过事件不伪称已经自动识别。唤醒后的模型语音应答保留为后续工作，本次先完成用户指定的表情设置。
