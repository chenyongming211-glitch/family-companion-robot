# 50人声纹扩容评测 Implementation Plan

> **For agentic workers:** 使用superpowers:subagent-driven-development实施和独立审查。用户已授权50人测试；直接main，无分支或worktree。

**Goal:** 在云端完成50位公开真人的大样本ERes2Net-base实验，并评估原阈值、独立校准与资源表现。

**Architecture:** 新增隔离evaluate-large入口，复用既有Go／sherpa-onnx worker、严格清单和提取逻辑；普通evaluate和产品行为保持。

**Tech Stack:** Go1.27.3现有云端工具链、sherpa-onnx-go-linux/v2 v2.0.1、锁定ERes2Net-base。

## Global Constraints

- 依据[50人设计](../specs/2026-11-04-speaker50-design.md)，人数恰好50，最多2048片段／2MiB清单；普通3～8人／128片段／128KiB约束不变。
- Go／ONNX／数据处理和运行测试全部在云端独立目录；Mac只编辑／Git。
- 不改产品／session阈值、模型、env／unit、VAD／AEC、固件；不接麦克风，不启动语音服务。
- 原始录音、声纹向量、凭据、模型、二进制、运行记录不进入Git。
- 不根据evaluation调参或挑样，不把相关配对或重复评分计成独立录音数。
