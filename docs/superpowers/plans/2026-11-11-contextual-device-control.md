**目标：** 当前轮交给模型判断查询、设置、含蓄反馈、指代和反话；不再用关键词决定模型是否有机会理解。现有设备桥接保留确定性执行与回执核验。

**接法：** 复用现有独立无声 Native 文本连接，每轮只提交一个服务器定义的结构化控制计划，模型不直接获得硬件设置工具；Go 校验整个计划后调用现有 Bridge 固定三工具。普通聊天也经过同一语义判断，初始语义预算3秒（含建立连接），不重试；18秒总路由预算仅用于确有控制计划的读取及最多两次设置。失败不放行任何模型自行设置。

## Global Constraints

- 只在 main 开发、提交、推送，不新建分支或 worktree。
- 所有运行测试、依赖、构建、真实模型评估只在云端；Mac只代码/Git和客户端，不复制私密配置、音频或用户对话。
- 不增加服务、框架或依赖；S3共用服务器逻辑，不刷固件，不触碰退货M5。
- 只操作当前已认证对话设备及实际发现的能力；其他目标不替换为当前设备。
- 每轮最多一个完整语义计划，严格JSON/schema、有限体积；先校验整个计划再执行。查询计划不能包含设置；字段仅volume/brightness，数值为0..100整数，每字段最多一次设置；取消/超时停止，不重试变更。
- 相对调整读取本轮设备新值后由Go计算，不用历史数字；未给幅度的小幅调整为10，边界限制在0..100。精确数值尊重明确请求；自动含蓄反馈不得大幅跳变。
- 仅ok且verified且回读字段/目标一致的结果可声称完成；缺字段、失败、部分成功、超时、取消分别如实提供语音事实，不编数值或声称撤销。
- 模型结合当前文本、最近本会话实际已播对话、最近已核验控制理解指代；历史不构成新授权。上下文有界，最多最近4轮已播对话、最近2条已核验操作且不超过3轮/5分钟，不读取其他会话记忆为控制授权，不用历史值作当前值。
- 普通夸奖、故事、引用、转述、否定、教学以及其他设备不触发误调；无上下文的反话歧义应澄清一次。语气音频本轮不引入，不能承诺识别所有讽刺。
- 普通聊天语义预算3秒，失败继续原语音但明确未核实控制；执行总预算18秒。真实供应商合成场景验证准确性与延迟，不用伪造模型响应代替语义验收。
