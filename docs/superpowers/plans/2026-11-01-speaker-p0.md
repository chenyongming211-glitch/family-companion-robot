# 声纹 P0：云端 Go 推理与会话内匿名说话人基础

> **For agentic workers:** 使用 `superpowers:subagent-driven-development` 或 `superpowers:executing-plans` 按任务实施，采用测试先行、规格后质量两阶段审查。遵守仓库约定：直接 main，不建分支/worktree；运行时检查全部在云端。

**Goal:** 获得可运行、可测量的 Go 声音特征提取与会话内访客区分基础，先验证模型和资源，不改变正式 Realtime 服务，不持久化访客特征。

**Architecture:** 主仓库新增不依赖原生库的 `internal/speaker` 状态/采样区间和匿名聚类；隔离 Go module 提供 ONNX worker 与评估入口，避免把实验原生库带入正式构建。worker 仅在云端运行，评估只用明确标注的合成测试音频；特征和 PCM 不输出到报告。

**Tech Stack:** Go1.25+、sherpa-onnx Go v2/ONNX Runtime、Unix socket、Go testing/race/vet；CAM++ 与 ERes2Net 候选。推理依赖及模型在云端固定版本和摘要。

**授权与范围：** 2026-11-01用户批准按设计开发，并明确未登记的人只需在当前会话区分、不要求姓名。首先完成本P0包；真实家庭质量校准、首人登记、产品接线、人物记录和个人检索仍按后续阶段执行，不把本次原型当完整功能交付。

**云端独立根：** `/opt/family-robot-validation/speaker-p0-20261101-1be02bf/`，含 source、models、evidence；不得覆盖任何运行中 checkout、配置或声音记录目录。现有2核/约3.7GiB服务器剩余磁盘约2.6GiB，下载前核大小，保留至少1GiB余量；不删除其他任务的缓存/备份。现有swap不修改，P0不处理真人声纹。

## Task 1：纯 Go 临时说话人状态与区间验证

**Files:**
- Create `internal/speaker/tracker.go`
- Create `internal/speaker/tracker_test.go`

一个 Tracker 仅属于一个不可变 session、stream generation 和 model revision，只在内存中保留最多8个临时模板，不创建文件、人物姓名或稳定person_id。调用者串行拥有它，不假装可并发共享。

- [ ] 先写行为测试，云端看到缺失实现导致的RED。用确定性向量验证A→B→A、相近候选拒识、短音频、混合/覆盖不全、错误session/generation/model、NaN/Inf/零向量、维度、容量、过期/重置与迟到区间。
- [ ] 配置固定scope/model、dimension、min_samples、match_threshold、new_speaker_threshold、margin和max_speakers。要求有限数值，`-1 <= new < match <= 1`，margin非负，容量/维度有明确上限。
- [ ] Observation带同scope/model、起止采样、embedding及`single_speaker / complete`质量事实；无质量证据不分配标签。乱序/过期/错误归属不改状态。
- [ ] 第一个有效声音产生本会话`guest_1`。`best >= match_threshold`且领先次优达到margin才复用；存在两个候选时，完全同分必须uncertain，即使margin为0也不选择第一个。只有`best < new_speaker_threshold`才产生新标签，恰等于new阈值也保守视作灰区。灰区返回uncertain，满员且明确新声音返回unknown；不把无法匹配的一律当新人。
- [ ] 固定首次模板，不用每次匹配自动吸收/更新，避免初期模板污染。复制输入向量，外部修改不能改变内部模板。重置/关闭释放引用并使旧scope结果无效。
- [ ] 返回仅含状态、临时label、revision与所属采样区间；不公开内部向量。每个新session重新编号，不据此跨会话关联。
- [ ] 云端GREEN、race和vet；提交本任务限定文件。

行为示意，具体导出类型在Task1实现时保持小而一致：

```go
// Different clean vectors produce different session-only labels;
// repeating A reuses A. No person name or persistent identity is involved.
a := []float32{1, 0, 0}
b := []float32{0, 1, 0}
// observe(a, span1) -> temporary / guest_1
// observe(b, span2) -> temporary / guest_2
// observe(a, span3) -> temporary / guest_1
// observe(mixed, span4) -> uncertain; no new label
```

Task1结束后先规格审查再质量审查，修复阻断问题后再进入Task2。

## Task 2：隔离模型worker与有界协议

**Files:**
- Create `tools/speaker-lab/go.mod`、`go.sum`
- Create `tools/speaker-lab/protocol.go`、`protocol_test.go`
- Create `tools/speaker-lab/main.go`、`main_test.go`
- Create `tools/speaker-lab/README.md`

使用嵌套module `familyrobot/tools/speaker-lab`，`replace familyrobot => ../..`；普通根目录`go test ./...`不引入ONNX依赖。初期将测试明确分为标准协议/CLI行为和需要模型的opt-in检查，不把跳过算成模型验收。

- [ ] 先测试协议拒绝过长/截断帧、错误版本、采样率、奇数字节、超8秒、路径/模型不匹配、重复/迟到请求；验证输出不含PCM、向量或输入文本日志。
- [ ] 接收长度前缀帧；header只带固定请求ID、scope/采样区间和长度，PCM使用binary payload，最大256000B。未知字段/尾部/类型不符拒绝，不在日志回显请求体。
- [ ] worker只绑定显式私有Unix socket，父目录拒绝组/其他用户访问，已有socket不自动删除；不提供TCP监听。单进程、单extractor、单次处理，模型CPU/1线程、debug关。
- [ ] 启动前校验模型文件regular、大小上限、固定SHA256、16k输入契约；模型错误返回固定码。worker未接收家庭数据库密钥，不创建模板库。
- [ ] 响应向受保护父进程IPC返回embedding维度/float32及时间统计；该IPC可以携带向量，但stdout/stderr、持久评估报告均不得输出向量。验证NaN/Inf、长度/维度、最大帧与请求归属。
- [ ] CLI支持`probe`：显式读取测试WAV，限制PCM16mono16k与8秒，产生无声音/向量的结果JSON；测试fixture的单说话人声明必须标为fixture-only，不能当已实现重叠检测。
- [ ] 实际模型执行在可被父进程终止的worker中；截止时间不满足时父进程杀掉并回收，旧结果不能被新请求接收。并发/队列上限在未来音频接线层实现，本P0不接Session队列。
- [ ] 用真实模型经IPC验证一次结果，再做错误摘要/截断输入/超时与干净退出；云端完整嵌套module测试、race、vet/build并提交。

协议版本为1；固定采样率16000、PCM16LE mono；单请求最多128000samples。向量最多1024维，验证维度来自锁定模型，不接受客户端随意选择模型路径。socket模式0600，父目录0700；需拒绝路径穿越与符号链接造成的权限绕过。

## P0后的推进条件

纯Go/IPC/合成声音结果可以证明工程基础和计算预算，不足以证明真实访客辨认。下一步需明确参与者、测试设备和仅RAM处理方式，取得实际目标人群的独立语音，完成原方案要求的质量校准和重叠/换人降级验证。达到门槛后才进入P1登记与P2正式音频试点；不以“合成声音识别率100%”替代这些条件。
