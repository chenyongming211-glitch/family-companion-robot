> **For agentic workers:** 本轮在当前会话直接完成 HTML 原型。后续正式功能按确认后的方案逐任务实施；不新建分支或 worktree。

**2026-11-09真实接入更新：** 用户已确认核心UI，首个独立Go管理服务与两端真实只读页面已实现并部署云端回环18791。只开放当前微雪本次绑定后的新记录；默认31页mock保留18790。账号/绑定使用云端私有配置，未引入数据库；设置、邀请、删除、记忆及30分钟业务聊天归档尚未接入。具体实施、验证与剩余实机步骤见[只读接入计划](2026-11-09-management-readonly.md)。以下“待UI确认/后端未开发”为此前阶段。

**2026-11-09实施更新：** 用户确认Vue 3及三批开发，两端31页mock前端已在`web/management/`实现，云端18项行为测试/类型检查/构建、完整依赖审计0漏洞和浏览器93项布局复核通过。当前待用户UI评审，管理后端未开发。三批执行与准确进度见[本轮计划](2026-11-09-management-frontend.md)；下方Task1～5保留为原HTML原型记录。

**最新执行顺序（2026-11-08用户明确）：** 先开发内部后台与家庭端前端，使用mock展示数据并预留统一接口层；用户看过UI、样式和交互、确认后，再开发管理后端并逐项对接。下方已完成的Task 1～5是已有HTML原型记录，不代表正式前端mock阶段已完成。前端框架已于2026-11-09明确并完成三批mock实现，当前进入UI评审。

**整体实现原则（同日用户明确）：** 满足当前需求即可，采用最小实现，复用已有代码；前端交互保持简单。31页原型是总体范围参考，正式前端分批交付；mock采用简单API函数和少量虚构数据，不引入通用适配器框架、状态场景引擎或无当前需求的依赖。

**Goal:** 先交付使用mock及统一接口层的两端前端供用户评审UI，确认后再开发和对接后端，分阶段交付真实聊天记录、能力管理和家庭数据隔离。

**Architecture:** 当前采用独立Go只读管理API、云端私有账号/绑定配置及Vue 3 + TypeScript + CSS双入口。PostgreSQL仅为后续建议，未引入；原HTML原型保留作参考。语音服务保持当前主路径，管理服务不调用设备麦克风或模型。

**Tech Stack:** 原型：语义化 HTML、原生 CSS、JavaScript、内联 SVG；正式前端采用 Vue 3、TypeScript、CSS、Vite，内部端评估 Element Plus，家庭端采用同一套领域类型和独立移动布局。正式依赖与运行测试只在云端执行。

**依据:** [平台方案](../specs/2026-11-08-management-platform-design.md)，包括已确认的第6.1节会话规则及最新第3.1～3.3节共用底层/故事故障前置约束（文档提交fed0a6d）。平台技术栈和视觉方案为本次建议，不将 HTML 预览当成后端已实现。

本页仅作总体方案的执行拆分与进度记录。前端比较和HTML原型为研究/评审附件；八类智能体共用能力统一收在[总体方案第3.4～3.6节](../specs/2026-11-08-management-platform-design.md#34-八类智能体共用能力及分期)，不另建第三份总体方案。下述P0B～P5路线与这些能力逐阶段对应，未确认选型和未实现功能保持待评审/待开发状态。

### 正式前端的语言与框架（Vue 3与核心UI已确认）

比较与取舍见[前端方案比较](../../research/2026-11-08-management-frontend-options.md)。Vue 3/React及SPA/SSR属于不同层次，此前推荐已于2026-11-09由用户明确选择Vue 3；后端政策仍分别评审。

- 当前建议采用SPA的前后端分离架构：同仓库内两个前端入口，内部后台与家庭手机网页各自布局，共享API类型、请求层及设计变量；统一访问Go管理API。
- TypeScript 是建议的主要开发语言，Vue单文件组件的template定义结构，CSS定义视觉；Vue 3组织组件和页面，Vite负责构建。
- 内部端优先评估 Element Plus 的表格、表单和权限相关页面组件，使用本原型的设计变量覆盖主题；家庭端保持简洁移动布局，复用领域类型和API客户端。
- 正式 API 类型与状态枚举统一；后端保存/权限/能力事实是权威，前端不另写一份能力开关规则。
- 数据存储建议 PostgreSQL；Eino 的执行检查点、聊天档案和设备记忆分清职责，借统一业务接口访问，不把 tracing 当成家庭聊天档案。
- 正式前端框架与依赖已锁定并完成P0A实现；核心UI确认后的只读真实接入见上述最新计划。前端构建、后端运行检查和部署在云端，Mac保持代码/Git与浏览器测试客户端定位。

## 4. 原HTML原型阶段的运行边界（历史记录）

仅创建静态原型和计划。现有Go正式服务、固件、600/300ms窗口、语音模型/音色、设备身份和声纹实验保持；不播放声音、开麦、刷机或操作硬件。虚构数据不参与任何声纹准确率或产品运行统计。
