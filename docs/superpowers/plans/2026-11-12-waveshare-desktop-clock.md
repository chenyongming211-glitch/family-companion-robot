# Waveshare Desktop Clock Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development for the approved B design, with an independent task review and final review. Direct main only; no worktree.

**Goal:** Implement the selected B desktop clock on the supported Waveshare ESP32-S3 2.16 firmware, with truthful time and existing voice/system-page priority.

**Architecture:** The existing ChickFaceView owns clock widgets and layout under the display lock. A small portable desktop-clock helper owns wall-clock formatting and display-mode/layout rules. Existing OTA/server time and board power-save/brightness remain authoritative; no new service or time-sync stack.

**Tech Stack:** Existing C++17/ESP-IDF6.1/LVGL9/Python host harness, cloud runtime and native build.

## Global Constraints

- Develop, commit and push directly on main; do not create branches/worktrees. Preserve unrelated audio-capture edits and M01 note.
- Supported product firmware is Waveshare ESP32-S3 2.16 only. No M5/C3 builds or release gates; retain historical sources.
- B is already user-approved, and the user now explicitly requests development. Do not request design approval again.
- Standby: warm large HH:mm, Chinese date/weekday, small current CHICK-01 face and truthful bottom state. Conversation: compact top time, original large face/mouth and actual state.
- Low-brightness standby: static clock/date, hidden face; reuse current 60-second power-save and brightness policy. Do not force always-on, create fixed night hours or write preferences.
- Unsynchronized/invalid clock shows --:-- and no invented date. OTA currently adds timezone_offset to epoch before settimeofday; do not apply +8 again. Valid local wall clock keeps advancing offline. No seconds/blinking/new model calls.
- Time/date text updates on minute/date or validity changes; layout updates on real state/page transitions. Screen-off pauses the existing display timer; wake refreshes current time.
- Configuration, error, upgrade and notification/system pages keep priority; preserve 48px left/right top icon safe margins and current connection diagnostics/music audition.
- Dependencies, runtime tests and firmware builds run on cloud. Mac is code/Git and later test client only. No device flashing in this development task; create a verified candidate first. User is currently away.
- Final candidate must retain at least32KiB app-slot headroom; do not expand partitions or remove current music/diagnostic features to fit the clock.
- Keep generated firmware/media/backups/credentials outside Git. No new frontend, server, catalog, audio changes or speculative framework.
