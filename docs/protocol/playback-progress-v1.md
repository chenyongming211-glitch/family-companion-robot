# 设备播放回报 v1

本扩展仅增加元数据，不改变小智 v1/2/3 的 Opus 二进制封装。源音频24kHz、单声道；下行固定60ms、每包1440采样。辅助 ASR 不在本阶段范围。

## 协商与身份

设备 hello 在功能可用时声明 `features.playback_progress_v1=true`；网关 hello 返回同名 true 才启用。任一方不支持时保持原有语音，不生成“已确认播放”的状态。

网关为每个实际 TTS 播放块分配非零 uint32 `playback_id`，当前设备 WebSocket 会话内严格递增、不重复，耗尽即结束连接。`session_id` 必须等于服务端 hello 的值；设备重连清空所有进度。一个工具父回复及其语音续答共用现有 TTS 块及播放代号。已发送计数只在成功写出二进制包后增加1440采样，补零的最后一帧也按实际发送长度计入。TTS start/stop 携带匹配代号，sentence_start 可以附带同一代号；正文不是已播证据。

```json
{"type":"tts","state":"start","session_id":"opaque-session","playback_id":1}
```

帧按 WebSocket 顺序归属此块。固件必须在入解码队列时保留该代号、设备本地连接代次和接收侧音频采样偏移，并贯穿在途解码、输出、DMA。不能在任务执行时重新套用“当前代号”。提示音和通知音必须使用独立身份，不能增加服务器 TTS 进度。

## 回报

```json
{"type":"playback","state":"progress","session_id":"opaque-session","playback_id":1,"sample_rate":24000,"played_samples":4800,"valid":true,"basis":"i2s_dma"}
{"type":"playback","state":"finished","session_id":"opaque-session","playback_id":1,"sample_rate":24000,"played_samples":5520,"valid":true,"basis":"i2s_dma","interrupted":true}
```

`played_samples` 是该块从0起**连续且已在 I2S TX 完成**的采样前缀，不是墙钟估算、收包计数、解码计数或提交计数。不使用全局 TX 计数推算回复归属。I2S 完成证明数字发送边界，不证明人听清，也不测量 DAC、功放和空气传播延迟。

progress 最快每200ms一次，finished 尽快发送一次；从正常任务发送 JSON，ISR 不分配、不发网络、不输出日志。相同前缀的重复 progress 可忽略；倒退、超出已下发样本、错误会话/代号、非整数、错误采样率/依据不允许改变有效暂停记录。

正常 stop 仅封口：等待该块的解码、软件队列及其 DMA 标签全部完成才 finished；临时断流不等于结束。interrupted stop 先清旧软件队列，已进入 DMA 的尾部实际发送后才给出最终前缀。不允许将清掉的未播音频计入进度；不阻塞立即停播/新收音。

格式变化、硬件重开、解码丢帧、队列丢弃或任何无法证明前缀连续的情况，回报 `valid=false`，不得再把旧前缀升级为精确进度。同一身份一旦收到合法的 `valid=false` 回报，其位置未知状态不能被后来的 true 恢复；已结算的最终回报保持不变。结束后的迟到事件、旧连接/旧播放代次不能作用到新块。固件可为无法支持的跟踪安全降级，但必须保留普通对话且不冒报 valid=true。

## 有界资源与暂停状态

固件新增 PCM 队列、DMA 身份标签和回报快照采用固定容量，新增内部 SRAM 目标不超过16KiB；不在 ISR 使用 mutex、std::atomic 或动态容器。沿用现有 ISR/task 临界区保护共享状态，不能在锁内阻塞。保留既有 AEC 参考读取在重填 DMA 之前，保证参考取自刚实际发送的内容。

网关最多保留16份轻量播放记录，以及一份暂停任务。已发送采样数与已确认采样数分别记录；上游重连不丢弃尚待最终回报的暂停任务，设备连接关闭则全部失效。只有服务端正常封口、设备有效 finished、非中断且确认前缀等于全部已发送采样时，相关历史才能从 transport_sent 升为 playback_confirmed；generated_text 仍是生成稿标签，不等于外部逐字转写。无需在这一阶段新增音频留存；文字映射阶段再确定需要的有界音频窗口。

暂停任务保存原用户请求、任务代号、播放代号及确认位置，不以最后一个助手生成稿代表暂停位置。旁支问答完成或再次中断不会覆盖原任务。提供本地上下文工具查询/显式放弃或切换任务，所有修改需匹配任务代号；新任务取自当前已收到的用户转写。显式切换创建新的任务代号，不继承旧播放位置；尚未关联的播放位置保持未知，也不自动绑定后续无关旁支。未经文字映射，`text_position` 始终是 unknown，继续时不能假称已知道暂停字词。

原有12条历史、每条512字的限制保持。暂停请求最多512字，截断时明确保留不完整标志；不持久化、不记录原文或音频。连续对话不得导致播放记录或任务记录无限增长。闲置/断开按既有生命周期清理。
