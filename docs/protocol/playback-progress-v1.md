# 设备播放回报 v1

本扩展仅增加元数据，不改变小智 v1/2/3 的 Opus 二进制封装。源音频24kHz、单声道；下行固定60ms、每包1440采样。辅助 ASR 不在本阶段范围。

## 协商与身份

设备 hello 在功能可用时声明 `features.playback_progress_v1=true`；网关 hello 返回同名 true 才启用。任一方不支持时保持原有语音，不生成“已确认播放”的状态。

网关为每个实际 TTS 播放块分配非零 uint32 `playback_id`，当前设备 WebSocket 会话内严格递增、不重复，耗尽即结束连接。`session_id` 必须等于服务端 hello 的值；设备重连清空所有进度。一个工具父回复及其语音续答共用现有 TTS 块及播放代号。已发送计数只在成功写出二进制包后增加1440采样，补零的最后一帧也按实际发送长度计入。TTS start/stop 携带匹配代号，sentence_start 可以附带同一代号；正文不是已播证据。

```json
{"type":"tts","state":"start","session_id":"opaque-session","playback_id":1}
```

帧按 WebSocket 顺序归属此块。固件必须在入解码队列时保留该代号、设备本地连接代次和接收侧音频采样偏移，并贯穿在途解码、输出、DMA。不能在任务执行时重新套用“当前代号”。提示音和通知音必须使用独立身份，不能增加服务器 TTS 进度。

## 回报

```json
{"type":"playback","state":"progress","session_id":"opaque-session","playback_id":1,"sample_rate":24000,"played_samples":4800,"valid":true,"basis":"i2s_dma"}
{"type":"playback","state":"finished","session_id":"opaque-session","playback_id":1,"sample_rate":24000,"played_samples":5520,"valid":true,"basis":"i2s_dma","interrupted":true}
```

`played_samples` 是该块从0起**连续且已在 I2S TX 完成**的采样前缀，不是墙钟估算、收包计数、解码计数或提交计数。不使用全局 TX 计数推算回复归属。I2S 完成证明数字发送边界，不证明人听清，也不测量 DAC、功放和空气传播延迟。

progress 最快每200ms一次，finished 尽快发送一次；从正常任务发送 JSON，ISR 不分配、不发网络、不输出日志。相同前缀的重复 progress 可忽略；倒退、超出已下发样本、错误会话/代号、非整数、错误采样率/依据不允许改变有效暂停记录。

正常 stop 仅封口：等待该块的解码、软件队列及其 DMA 标签全部完成才 finished；临时断流不等于结束。interrupted stop 先清旧软件队列，已进入 DMA 的尾部实际发送后才给出最终前缀。不允许将清掉的未播音频计入进度；不阻塞立即停播/新收音。

格式变化、硬件重开、解码丢帧、队列丢弃或任何无法证明前缀连续的情况，回报 `valid=false`，不得再把旧前缀升级为精确进度。同一身份一旦收到合法的 `valid=false` 回报，其位置未知状态不能被后来的 true 恢复；已结算的最终回报保持不变。结束后的迟到事件、旧连接/旧播放代次不能作用到新块。固件可为无法支持的跟踪安全降级，但必须保留普通对话且不冒报 valid=true。

## 有界资源与暂停状态

固件新增 PCM 队列、DMA 身份标签和回报快照采用固定容量，新增内部 SRAM 目标不超过16KiB；不在 ISR 使用 mutex、std::atomic 或动态容器。沿用现有 ISR/task 临界区保护共享状态，不能在锁内阻塞。保留既有 AEC 参考读取在重填 DMA 之前，保证参考取自刚实际发送的内容。

网关最多保留16份轻量播放记录，以及一份暂停任务。已发送采样数与已确认采样数分别记录；上游重连不丢弃尚待最终回报的暂停任务，设备连接关闭则全部失效。只有服务端正常封口、设备有效 finished、非中断且确认前缀等于全部已发送采样时，相关历史才能从 transport_sent 升为 playback_confirmed；generated_text 仍是生成稿标签，不等于外部逐字转写。无需在这一阶段新增音频留存；文字映射阶段再确定需要的有界音频窗口。

暂停任务将原用户请求与最新播放段分开保存，不以助手生成稿代表暂停位置。旁支问答不能覆盖原任务；显式恢复的播放段属于同一任务，再次打断时更新到该新段，旧段迟到回报不能覆盖新段。恢复后的正常完整数字交付只令 `latest_block_delivery_complete=true`，不证明原目标已完成，也不删除原请求；当前保留到显式放弃或切换。

本地查询工具 `conversation_get_paused_task` 与自动注入模型的 `paused_task` 使用同一份单调 `revision` 快照。当前有保存任务时，每个新用户输入先使用已经存在的、匹配输入身份的千问转写，在独立短连接中做文字分类。只发送原请求、最新用户文字和网关保存的 `awaiting_resume_choice` JSON，不发送音频、不请求ASR、不提供工具；只接受completed响应中的严格 `side`、`resume`、`restart`、`resume_from`、`discard`、`replace` 单枚举。查询任务/进度和旁支问题归为side；普通继续为resume，明确允许从头重读为restart，用户明确给定起点为resume_from。单独回答起点只有在同一任务确实等待选择时才能成为resume_from。

任务身份、输入身份和版本由网关捕获并复核，不要求模型复制版本数字。只有事件循环能应用结果；新输入、打断、重连/断开取消旧分类，迟到结果不改变新状态。版本在途变化则重新判断，最多三次尝试；分类会话每次最多8秒，现有转写等待也有8秒期限。缺失、不完整/截断、匿名的归属输入不能默认为恢复。分类正文、音频或工具事件不注入主语音上下文；格式不符或失败不能放行未绑定语音。

`resume`、`restart`、`resume_from` 由网关应用同一个恢复绑定，保留不同的生成策略。位置未知且没有用户指定起点或重读许可时，resume只请求固定澄清：“我还不能确认刚才停在哪儿。请告诉我从哪里继续，或从头再来。”等待选择属于带revision的网关状态；旁支保留，明确选择、放弃、切换或断开清理。澄清回复也绑定原任务，不视为原目标完成。

这条短澄清使用同一千问原生语音响应，先暂存PCM，直到completed、audio.done、匹配的完整转写均已到达；只有Unicode标点和空白可忽略。验通过前不发送TTS start、sentence或音频。PCM最多15秒（24kHz单声道16位，720000字节）、从请求起8秒完成期限；正文不符、额外工具/文字、无效音频、失败/取消状态或超时关闭本次会话，不能重用未播上下文。用户插话或abort仍立即清除暂存并走原停止/重连流程。明确许可后可按原目标从头或用户指定处继续；该起点是用户指令，不是测得的已播文字。

恢复绑定覆盖随后的语音回复及设备工具续答；`replace` 创建新任务代号，原请求仅取自当前实际用户转写，不继承旧位置。普通语音阶段只提供暂停查询工具；兼容的本地变更实现仍要求匹配 `task_id`/`expected_revision`，且已完成归属后拒绝重复变更。未经映射，`text_position` 始终是unknown。

主语音会话保持原来的角色、tools和text/audio模态，不进入路由角色。原生VAD使用 `create_response=false`、`interrupt_response=true`。接受分类后及每次生成前同步当前instructions快照，不重发不可修改的VAD/音频格式；等匹配 `session.updated` 后才 `response.create`。快照在途变化时重新同步，mode ACK不能解锁生成。8秒收不到快照ACK则结束连接。ACK按WebSocket顺序匹配，不依赖服务端未提供的客户端事件ID回显。新输入使旧生成请求失效，但保留其ACK FIFO占位，快照token继续递增，不能复用；只有当前输入代次/身份、已接受归属和当前快照均匹配的ACK才能放行。

早先尝试同会话路由的 `tool_choice=required` 实测只被接受/回显，不能强制函数调用；该候选在真实链路输出路由正文后被保护关闭，未部署，现已被独立分类替代。即使独立分类输出异常，它也不可能直接进入设备播放队列；主会话在归属及快照ACK前不得生成。六枚举协议14条独立原生样本分类耗时约0.33～0.54秒，不是物理插话停播延迟，也不是生产延迟保证。

打断 stop 与上游重连不等待最终回报。后续生成最多等到中断起点后250ms；缺少最终回报时保留 `settled=false`、`settlement_timed_out=true`，采样位置转为 unknown。后来的 progress 不能解除超时，有效匹配 final 可以更新结算。最新状态在后续生成边界自动同步，不再依赖模型主动查询。被中断块的未播生成稿从模型历史中移除，包含已发完但设备未播完，以及已退休的共享工具块。

原有12条历史、每条512字的限制保持。暂停请求最多512字，截断时明确保留不完整标志；不持久化、不记录原文或音频。连续对话不得导致播放记录或任务记录无限增长。闲置/断开按既有生命周期清理。
