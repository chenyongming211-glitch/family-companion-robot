# Task2 独立规格与质量审查

读取 task-2-brief.md（需求）、task-2-context.md（已确认接口）、task-2-report.md（实现及测试）、由控制者指定的不可变 diff 包。审查实际代码是否满足需求，而非仅相信报告。不要改产品源码、不操作设备/生产、不重复已通过且未改变的完整套件。若有具体新疑点，可最小复现并记录。

重点检查：双向协商和严格数字/字段；旧或错误回报不污染当前；16条有界记录与最终/无效锁定；工具共享块、尾帧累计；历史仅正常完整播放升级；上游重连与设备会话生命周期分开；晚到 STT 的原任务归属；仅一份原任务且旁支不覆盖；只读/替换/丢弃工具的实际编排和代次/任务约束；没有标注时文字位置为 unknown、没有额外音频留存。检查设备 MCP 控制能力与本地工具独立，无 MCP 时普通问答仍可用。

分别给出规格符合性与代码质量 verdict，所有问题附严重程度、实际路径/行号与触发证据；任何不能从 diff 核实的跨任务项明确列出。报告写 task-2-review.md，返回简明结论。真实词级定位和实机 AEC 不由此审查推定通过。
