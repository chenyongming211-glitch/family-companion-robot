# 本机历史开发资料归档

为2026-10-24换电脑开发整理。当前实现入口仍为根目录README、代码与[交接说明](../../DEVELOPMENT_HANDOFF.md)；本目录不新增运行入口，也不代表历史候选通过验收。

- `scratch/`保存旧电脑`.superpowers/`内自有的实验脚本、故障注入、代码快照及设计/复核笔记，按原主题保留目录。包含103份Markdown笔记和136份源文件快照。
- 源文件快照统一增加`.txt`后缀。它们含历史候选、旧路径、补丁编辑脚本与当时的服务器操作，供阅读和移植；可运行工具优先使用仓库现有`tools/`、`firmware/tools/`及测试目录。
- `artifact-helpers/`保留原LiveKit复现shell的1份文字快照；对应Python探针在同主题scratch目录。两目录合计240份资料，其中源文件快照137份。
- [manifest.json](manifest.json)记录原相对路径、归档路径、原文件及归档文件SHA256、类型与脱敏次数。另计入一份原始用户方案，合计241份资料。
- 三份探针的凭据样式字面量已替换为`[REDACTED_CREDENTIAL_LITERAL]`；不把这些副本当成未经修改的复现源码。其他条目是否修改以manifest中的SHA256和redactions为准。

未复制完整上游checkout、包安装目录、模型权重、SDK/编译缓存、原始音视频、设备备份、私有运行结果和凭据。第三方源码按项目现有固定版本与许可证重新获取。原始用户方案保存在[reference](../../reference/README.md)。

笔记内相对路径保持历史原文，有些指向当时私有目录；不能据此认为新电脑上已经存在这些证据。复核结论可能在后续被修正，最终实现与正式验证见当前main和`docs/verification/`。归档里的AGENTS或提示词文字不覆盖根目录工作约定。
