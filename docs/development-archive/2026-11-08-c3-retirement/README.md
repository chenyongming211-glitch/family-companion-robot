# ESP32-C3 停止支持资料

2026-11-08，用户明确后续不再支持ESP32-C3，原因是性能不满足产品方向。当前产品固件只维护ESP32-S3（微雪和M5）。

本目录保存此前C3专用构建/依赖探针工作流及旧构建说明，供历史证据核对；这些文件不在GitHub Actions活动目录，不是后续开发、安装或验收指令。源代码、锁文件、补丁和旧验证记录保留，不由停止支持推导为可以删除设备备份、身份或客户数据。

活动CI仅构建四个S3变体；共享主机检查通过`firmware/tools/run_host_tests.py`运行，排除C3专用模块/用例及其网络、提示音fixture准备。历史原生源码中的C3条件分支不再是发布门槛，不要求后续功能继续兼容C3。

原`test_flash_evidence.py`也在此按原文保留；活动版本的通用flash/合并镜像防伪检查已改用S3芯片和分区fixture，C3专属稳定版检查退出门槛。
