装配顺序

总装 8 道工序，单台工时约 4.5 分钟。屏幕与盖板的贴合是良率关键，建议单独设一个「屏幕预装工位」并做点亮检测。

屏幕预装（关键工位）亚克力盖板背面贴 0.15mm 双面胶 → 放回字泡棉 → 放 LCD 对位 → 点亮检测（白/红/绿/蓝/黑五色画面查亮点与漏光），合格后流入总装。
前壳组件盖板组件从前壳内侧压入，四周均匀施力；屏幕支架从背面卡入 4 个卡扣，打 2 颗 M2×6 自攻螺丝，扭矩 0.15N·m。
提环与翅膀提环卡扣压入前壳顶部（听到「咔」两声）；翅膀软胶从外侧穿过前壳开孔，内侧贴轻触开关与回弹垫。
主板装配主板 3 颗 M2×5 螺丝固定于前壳螺柱；插屏幕 FPC（锁扣翻盖式，注意金手指朝下）、双麦线、喇叭线。
音腔与喇叭喇叭装入音腔件，四周打密封胶；音腔压入后壳定位槽，出音孔对正，确保无缝隙漏气（漏气会损失 6dB 低频）。
电池与配重18650 卡入底部电池仓（贴 1mm 泡棉防震），XH2.0 插头接入；30g 配重块粘于底壳前部，把重心往前下方拉。
合壳后壳与前壳对位（4 个定位柱先入），周圈 6 颗 M2×8 螺丝，扭矩 0.2N·m，顺序对角交叉，避免壳体变形导致缝隙不均。
测试与老化烧录固件 → 触摸/按键 → 麦克风回环 → 喇叭扫频 → 充电测试 → WiFi 配网 → 2 小时老化，最后贴脚垫与包装。
05

固件架构

基于 ESP-IDF v5.x + LVGL 8.3，双核分工：Core 0 跑显示与网络，Core 1 跑音频链路，避免动画卡顿影响拾音。表情由语音状态机驱动，不需要手动触发。

拾音INMP441 双麦 → I2S RX16kHz / 16bit / 单声道
前端处理AFE + VAD + 唤醒词ESP-SR WakeNet「你好小鸡」
编码上行Opus 16kbps / 20ms 帧WebSocket

状态机：IDLE → LISTEN → THINK → SPEAK → IDLE，超时 30s 回 IDLE 并闭眼
云端 ASR → LLM → TTS流式返回，首包 < 800ms
下行播放MP3/AAC 流式解码 → I2S TXMAX98357A → 喇叭
口型同步按音频包络驱动嘴形无需音素对齐，成本最低
表情系统设计：用 LVGL 画「两个椭圆眼 + 一条贝塞尔嘴」，只改参数就能覆盖 90% 情绪。眼高（blink）、眼距、嘴角弧度、瞳孔位移四个变量即可组合出：待机（缓慢眨眼）、聆听（瞳孔放大+微微上抬）、思考（眼睛左右扫视）、说话（嘴形跟随包络）、开心（眼睛弯成月牙）、困了（眼皮半合+低头）。不需要逐帧动画资源，整张脸代码不到 300 行。
三个容易踩的坑：① PSRAM 不开启会导致 LVGL 帧缓冲分配失败、屏幕花屏 → 编译选项务必勾选 Octal PSRAM 80MHz；② 双麦若走同一个 I2S 控制器做立体声，两个麦的时钟会互相干扰，建议主麦单独 I2S、副麦用 ADC 或分时复用；③ 喇叭和麦克风距离小于 40mm 会啸叫，结构上让喇叭朝下、麦克风朝前，可天然隔离。
