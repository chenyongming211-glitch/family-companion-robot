建议测试顺序

  1. 检查电平、试听提示音，确认设备正常。
  2. 连接后点“开始说话”，问“一加一等于几”，点“结束发送”，听到回答。
  3. 再次点“开始说话”，说“从一数到五十”，点“结束发送”；播放中点“立即停播”。
  4. 重新点“开始说话”，问“二加三等于几”，点“结束发送”，确认新回答正常。

当前是点击分轮：停播后不会自动收下一句话。只在点击“开始说话”后发送麦克风音频到已配置的云端语音模型。不保存录音或对话正文；断开会释放麦克风。浏览器回声消除不等于 ESP-SR 或手表 AEC 已验证。
