# 伴伴管理平台 · 两端前端

Vue 3＋TypeScript＋CSS＋Vite。管理后台与家庭网页始终使用同源真实管理API；默认构建只有真实两端，没有演示数据、演示存储或模式开关。设备当前产品支持范围为微雪 ESP32-S3。

内部入口为 `index.html`，家庭入口为 `family.html`。当前真实管理服务经既有 SSH 转发访问 `http://127.0.0.1:18791/index.html` 与 `http://127.0.0.1:18791/family.html`。账号、密码与权限沿用服务端配置，凭据不进入仓库。部署和现场验收状态以[开发交接](../../docs/DEVELOPMENT_HANDOFF.md)及相应验证记录为准。

## 已接入行为

账号密码登录/退出、授权家庭/设备/账号、绑定后的聊天列表/详情、近期记忆列表/详情与来源聊天、设备心跳/音量/亮度控制、近期记忆清除，以及内部操作审计。名称/位置编辑、成员邀请/权限编辑、聊天删除与留存策略写入尚未接入，网页不提供对应表单。

未上报遥测保持未知值。聊天按明确结束或轮次结算后30分钟无有效交流归档，跨零点不拆分；缺少终态或记录尚未完整时保持待结算/更新中。详情分别显示最终转写、可靠已播文字、生成稿、播放和保存状态，不提供原音播放。

近期记忆为本次绑定后最近7天、最多24轮的上下文片段，可能截断，不等同于完整档案或长期人物记忆。清除要求当前授权正文读取成功与设备管理权限，经一次确认、匹配设备的 confirmed 回执后重新读取；聊天档案保留，新对话可产生新记忆。

## 云端验证与构建

依赖安装、测试、类型检查和构建仅在云服务器执行；Mac用于代码/Git与浏览器客户端。Node要求 `>=22.18`。

```sh
cd web/management
npm ci --registry=https://registry.npmjs.org
npm test
npm run typecheck
npm run build
```

默认 `dist/` 包含真实内部与家庭两入口。`npm run build` 也会先运行类型检查。管理服务部署与私有账户配置见[部署说明](../../deploy/management/README.md)。不要启动本地语音服务或将服务器凭据复制到Mac。

## 代码与安全边界

| 位置 | 职责 |
| --- | --- |
| `src/App.vue`、`navigation.ts` | 双端既有布局、真实页面目录、hash导航与会话反馈 |
| `src/api.ts`、`remote-api.ts`、`api-error.ts` | 默认真实API、同源HTTP契约与独立错误类 |
| `src/pages/CorePages.vue` | 设备、聊天与真实设备设置 |
| `src/pages/DataPages.vue` | 登录、授权家庭/账号与近期记忆 |
| `src/pages/AuditPage.vue`、`audit-control.ts` | 内部操作审计、筛选与分页 |
| `src/runtime-control.ts`、`components/RuntimeControls.vue` | 共用控制/清除流程、回执匹配与50秒观察窗口 |
| `src/sensitive-session.ts` | RAM请求代次、隐藏/pagehide/账号失效通知 |
| `tests/*.test.ts` | 隔离真实HTTP输入、挂载页面及运行状态/隐私行为验证 |

会话由 HttpOnly cookie 保存，正文仅保留页面内存。admin/family会话独立；退出、受保护请求401、已知账号过期或身份变化均隔离迟到请求。匿名session401仅返回未登录，不使登录组件自身加载失效。隐藏、pagehide、卸载、切换设备清除敏感状态/定时器，重新进入读取新状态；不会持久保存Cookie或正文。

设备列表每5秒更新前台心跳，详情/配置共用控制组件每2秒刷新。滑块0..100、每10一档、11圆点，input只预览、change提交一次。已有 queued/sent 禁止新提交；控制器匹配设备、作用域、boot、命令ID、字段、目标、confirmed及实际读值。PUT、观察GET、清除及重读均有50秒截止，未知结果不重试，迟到回执不能改为成功；同页刷新不解除未结束的清除保护。

审计只显示平台已记录的获授权操作。访问只表示已记录；缺失回执保持未知，不以当前数值补历史回执。语音指令和设备按键尚无管理审计来源。日期按浏览器本地日历转换为UTC半开区间；默认50条，筛选改变重置分页，历史设备无当前权限则不提供跳转。
