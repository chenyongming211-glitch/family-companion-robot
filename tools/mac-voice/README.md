# MacBook 语音测试

Mac只运行Chrome与SSH转发，页面和模型链路都在服务器。已有8000服务不切换。使用MacBook扬声器或耳机均可；首轮是点击分轮，尚未实现自由说话自动打断。

在Mac终端执行（也可以在Finder双击`open.command`）：

```sh
./tools/mac-voice/open.command
```

使用自己的SSH登录方式；如果sudo提示权限不足，按服务器既有授权处理，不把密码写入脚本。保持终端窗口开启；按回车关闭本次隧道。默认只绑定Mac的127.0.0.1:18010，端口占用可用`VOICE_LOCAL_PORT=18011 ./tools/mac-voice/open.command`。

脚本通过SSH在服务器读取专用客户端令牌，领取120秒一次性配对链接并打开Chrome。长期令牌/模型Key不会传到Mac。页面立即清除URL fragment，换成900秒HttpOnly/SameSite cookie，并校验loopback Host和同源Origin。刷新页面或配对到期后重新运行入口；不要分享临时链接。

## 实测步骤

1. 点击“检查麦克风”，允许Chrome及macOS麦克风权限。说话时电平应变化；点击“试听提示音”，确认扬声器/耳机能听到声音。这两项不调用模型。
2. 点击“连接语音服务”。随后“开始说话”，说“一加一等于几”，点击“结束发送”。核对转写、文字回答与实际听到的声音。
3. 再点“开始说话”，说“从一数到五十”，点“结束发送”，在回复播放中点“立即停播”；确认实际声音是否马上停止。**停播后不会自动收下一句话**：重新点“开始说话”，问“二加三等于几”，再点“结束发送”，确认新回复正常。
4. 点击“断开连接”或“释放麦克风”。录音/连接期间保持测试页面前台，切到其他标签页会断开并释放mic。正文仅显示在当前页面，不写localStorage或录音文件。

每轮25秒自动结束、会话最多8轮/15分钟。连接后页面显示剩余时间/轮数，到期会明确提示；时间与轮数上限是分开的。达到8轮可断开后重新连接，配对过期则重新运行入口。连接过期不会自动重发问题，未完成的问题由用户决定是否重做。回声消除/降噪由浏览器请求并显示实际设置；不据此声称ESP-SR或手表AEC已通过。

## 事实边界

- “本地停播耗时”只测点击处理到执行停止命令，不是实际声学停声时间。
- 播放回报依赖`AudioContext.getOutputTimestamp()`估算输出采样前缀；不可用时报告unknown。不能用接收帧数、生成结束或此估算宣称精确字词接续。
- 真实听感/声音停播需要人在Mac前确认。未提供回环采样或外部麦克风声学计时；不会把服务器模拟播放器结果当成本机实测。
- 首版先停旧声音再开始新输入。自动端点、同时说话的声学插话、故事任务接续、手表接入另行验收。
